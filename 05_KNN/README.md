# K-Nearest Neighbors (KNN)

## 📌 Overview

Implemented the **K-Nearest Neighbors (KNN)** algorithm for classification using the **Iris dataset**.

## 🛠️ Technologies

* Python
* NumPy
* Matplotlib
* Scikit-learn

## 🔍 Implementation

* Loaded the Iris dataset
* Split data into training and testing sets
* Applied feature scaling using `StandardScaler`
* Selected the best K using cross-validation
* Trained the KNN classifier
* Evaluated using Accuracy, Confusion Matrix, Precision, Recall, and F1-score
* Predicted the class of a new flower

## ▶️ Run

```bash
pip install -r requirements.txt
python knn.py
```

**Supervised Learning | Classification | KNN | Feature Scaling | Cross-Validation | Model Evaluation**
