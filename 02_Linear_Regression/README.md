# Linear Regression

## 📌 Overview

Linear Regression is a supervised machine learning algorithm used to predict continuous numerical values by finding the best-fit straight line between input and output.

## 🎯 Objective

Predict student marks based on the number of hours studied.

## 🛠️ Technologies

* Python
* NumPy
* Matplotlib
* Scikit-learn

## 🔄 Workflow

1. Load dataset
2. Split data into training and testing sets
3. Train Linear Regression model
4. Make predictions
5. Evaluate the model
6. Visualize the regression line

## 📊 Results

* MAE: 0.50
* RMSE: 0.50
* R² Score: 0.9995
* Prediction for 7 hours: 74.33 marks

## 📈 Visualization

The project includes a plot showing the actual data points and the Linear Regression best-fit line.

## 📚 Key Learning

* Understanding Simple Linear Regression
* Train-test split
* Model training and prediction
* MAE, MSE, RMSE and R² evaluation
* Regression visualization
